## 2023-10-27 - Accessibility improvements
**Learning:** Adding `accessibilityLabel` with fallback to `label`, and `aria-invalid` if there is an error to the `TextInput` and `Button` components improves accessibility.
**Action:** Always add `accessibilityLabel` with fallback to `label`, and `aria-invalid` if there is an error to the `TextInput` and `Button` components.
